# Security policy

## Supported version

The current `main` branch and the version deployed at [claudiuschuster.de](https://claudiuschuster.de/) are supported.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting from the repository's **Security** tab and select **Report a vulnerability**. Include the affected page or file, reproduction steps, expected impact and any suggested mitigation.

Reports will be acknowledged as soon as practical. Confirmed issues will be handled privately until a fix is available and it is safe to disclose the details.
